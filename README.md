# Source codes of the website gaojh-cs.github.io

## Local preview

Run this command from the project folder:

```powershell
ruby _scripts/preview.rb
```

Open <http://127.0.0.1:4000/>. Changes to pages, styles, and images refresh the
preview automatically. Saving `_config.yml` also restarts Jekyll and refreshes
the browser, so changing `profile.avatar` no longer requires a manual restart.
Allow a few seconds for the rebuild. Press `Ctrl+C` to stop the preview.

This script is for local preview only; GitHub Pages uses its normal build.
